`.talos-tabs` is the in-console section switcher. The active tab carries an accent
underline tick that rides the row's shared bottom border — selection is a bright
hairline edge, never a heavy fill. State lives on ARIA: `aria-selected="true"` for tablists, `aria-current` for
tabs that are links. The markup encodes which tab is current, and the tick
follows it.

## Default

<Demo>
  <div class="talos-tabs" role="tablist">
    <button class="talos-tab" role="tab" aria-selected="true">Overview</button>
    <button class="talos-tab" role="tab" aria-selected="false">Metrics</button>
    <button class="talos-tab" role="tab" aria-selected="false">Logs</button>
  </div>
</Demo>

```html
<div class="talos-tabs" role="tablist">
  <button class="talos-tab" role="tab" aria-selected="true">Overview</button>
  <button class="talos-tab" role="tab" aria-selected="false">Metrics</button>
  <button class="talos-tab" role="tab" aria-selected="false">Logs</button>
</div>
```

Display-font, light weight, uppercase HUD tracking. `aria-selected="true"` scales
the accent underline in (`--talos-ease-glass`) and lifts the label to primary
text; hover brightens an unselected label. Toggle `aria-selected` in JS to switch.

```html
<div class="talos-tabs--segmented" role="tablist">
  <button class="talos-tab" role="tab" aria-selected="true">Day</button>
  <button class="talos-tab" role="tab" aria-selected="false">Week</button>
  <button class="talos-tab" role="tab" aria-selected="false">Month</button>
</div>
```

`--segmented` boxes the tabs into one control on the
[chamfer engine](/docs/components/chamfer/) (top-right cut) with hairline dividers.
The underline tick is dropped; the active segment fills to `--talos-surface-3`
instead. Inline-flex, so it shrinks to its contents.

## Link tabs with counts

<Demo>
  <nav class="talos-tabs">
    <a class="talos-tab" style="text-decoration:none" href="#" aria-current="page">Open <span class="talos-tab__count">12</span></a>
    <a class="talos-tab" style="text-decoration:none" href="#">Closed <span class="talos-tab__count">48</span></a>
    <a class="talos-tab" style="text-decoration:none" href="#">Drafts <span class="talos-tab__count">3</span></a>
  </nav>
</Demo>

```html
<nav class="talos-tabs">
  <a class="talos-tab" style="text-decoration:none" href="/open" aria-current="page">Open <span class="talos-tab__count">12</span></a>
  <a class="talos-tab" style="text-decoration:none" href="/closed">Closed <span class="talos-tab__count">48</span></a>
</nav>
```

For navigation between pages, render `<a>` tabs and mark the current one with
`aria-current="page"`; it shows the active state exactly as `aria-selected`
does. Anchors keep the browser underline unless you clear it
(`text-decoration: none`). `.talos-tab__count` adds a trailing tabular count.

## Classes

| Class | Effect |
| --- | --- |
| `.talos-tabs` | tab row; flex with a shared bottom hairline |
| `.talos-tabs--segmented` | boxed inline-flex control with hairline dividers, filled active segment, no underline |
| `.talos-tab` | a single tab button (display font, uppercase, light) |
| `.talos-tabpanel` | padded content region below the tab row |
| `[aria-current]` | marks the active tab for link navigation (anything but `"false"`); same look as `aria-selected` |
| `.talos-tab__count` | trailing count inside a tab — tabular, dimmed, tight to the label |
| `[aria-selected="true"]` | marks the active tab — scales in the accent underline (or fills the segment) and lifts the label to primary |
