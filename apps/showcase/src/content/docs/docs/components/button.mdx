`.talos-button` is the chamfered call-to-action. It rides the
[chamfer engine](/docs/components/chamfer/): a real 1px border, a `clip-path`
that cuts the bottom-right corner, and a 1px diagonal drawn along the cut, so the
hairline is continuous round the corner at any width. Emphasis is
monochrome — variants move the edge brightness and fill, never the hue — so the
button reads its weight from contrast, not colour. Render `<a>` when it links,
`<button>` when it acts.

## Variants

  <a class="talos-button" href="#">
    <span class="talos-button__label">Primary</span>
  </a>
  <button class="talos-button talos-button--secondary">
    <span class="talos-button__label">Secondary</span>
  </button>

  </button>
</Demo>

```html
<a class="talos-button" href="#">…</a>
<button class="talos-button talos-button--secondary">…</button>
<button class="talos-button talos-button--ghost">…</button>
<button class="talos-button talos-button--solid">…</button>
```

`.talos-button` alone is the primary (bright edge, solid fill). `--secondary`
dims the edge for an alternative action; `--ghost` drops the fill to transparent
for a tertiary, text-weight control that fills only on hover. `--solid` is the
loud call to action: light fill, dark label.

```html
<button class="talos-button talos-button--xs">…</button>
<button class="talos-button talos-button--sm">…</button>
<button class="talos-button">…</button>
<button class="talos-button talos-button--lg">…</button>
```

Default (md) is `2.5rem` tall. `--xs` is `1.75rem`, the same height as a
[`.talos-flag`](/docs/components/chamfer/#flag), for dense rows. `--sm` tightens height + padding for toolbars;
`--lg` grows to `3rem` with wider padding for a hero CTA. Combine one variant
with one optional size: `talos-button talos-button--ghost talos-button--sm`.

```html
<button class="talos-button" disabled>Locked</button>
```

`[disabled]` / `:disabled` dims to 0.5 and removes pointer events.

```html
<button class="talos-button talos-button--ghost" aria-pressed="true">Pressed</button>
<a class="talos-button talos-button--ghost" href="/docs/" aria-current="page">Current</a>
```

`aria-pressed="true"` (toggles) and `aria-current` other than `false`
(current-location links) recolour the edge and label to `--talos-accent`. The
state lives on the ARIA attribute, so the markup and the look cannot disagree.

## Markup

`.talos-button` needs no child element: a bare `<a>` or `<button>` carries the
cut. The optional `.talos-button__label` wraps content that mixes text and icons.
The Astro `<Button>` renders the same markup:

```astro
---
import { Button } from "@j_shelfwood/talos-ui/astro";
---
<Button variant="ghost" size="sm" href="/launch">Launch</Button>
```

```html
<a class="talos-button" href="/launch">Launch</a>
```

## Classes

| Class | Kind | Effect |
| --- | --- | --- |
| `.talos-button` | base | primary — solid fill, bright edge, md size |
| `.talos-button--secondary` | variant | dimmer edge, alternative action |
| `.talos-button--ghost` | variant | transparent fill, fills on hover |
| `.talos-button--solid` | variant | light fill, dark label — the loud call to action |
| `.talos-button--xs` | size | dense — `1.75rem`, tight padding |
| `.talos-button--sm` | size | compact — `2.25rem`, tighter padding |
| `.talos-button--lg` | size | hero — `3rem`, wider padding |
| `.talos-button__label` | element | optional content wrapper (inline-flex, inherits the gap) |
| `[aria-pressed="true"]` / `[aria-current]` | state | accent edge + label |
| `[disabled]` / `:disabled` | state | dims to 0.5, blocks pointer events |
