import Demo from "../../../../components/Demo.astro";

`.talos-timeline` draws runs of work on a shared time axis: one chamfered lane
per group, bars whose **fill pattern** says what started them, a **mark** at the
end of each bar for its result, curved edges between runs, and a side drawer for
one item's detail. No hue carries a category; only the status marks use the
status tokens. Lives in `talos-timeline.css` (in `all.css`); it needs `talos.css`
for the chamfer engine and `talos-layout.css` for the pulse of the live mark.

The caller computes every position in px and passes it as a custom property:
`--x`, `--w`, `--y` on bars and events, `--x` on ticks, and
`--talos-timeline-width`, `--talos-timeline-hour` (px per hour) and
`--talos-timeline-hour0` (x of the first hour rule) on the root. The same numbers
place the SVG edge paths, which live in the tracks' px space (axis and lane
gaps included). A head and its lane share a height and read as one chamfered
panel: the head carries the bottom-left cut, the lane the top-right cut. The
label column scrolls with nothing; the tracks scroll horizontally inside
`__viewport`.

The bar variants set paint only, never position, so the same class dresses a
legend swatch. Put the swatches in toggle flags (`<button class="talos-flag"
aria-pressed>`) and the legend doubles as the filter: a pressed flag shows its
runs, an unpressed one is struck through.

| Class | Encodes |
| --- | --- |
| `.talos-timeline__bar--solid` | started by a person |
| `.talos-timeline__bar--outline` | started by a supervisor or scheduler (outline, half-tone fill) |
| `.talos-timeline__bar--hatched` | delegated work (diagonal hatch) |
| `.talos-timeline__bar--dotted` | background or other work (dotted outline) |
| `.talos-timeline__bar--muted` | a run that changed nothing (25% opacity, dashed) |

| Class | Encodes |
| --- | --- |
| `.talos-timeline__mark--merged` / `--opened` | success-token filled / hollow square |
| `.talos-timeline__mark--decision` / `--failed` | warning-token chevron / danger-token x |
| `.talos-timeline__mark--posted` / `--live` | hollow dot / the accent pulse (still running) |
| `.talos-timeline__event` (`--solid`, `--faint`) | a point in time: hollow, solid or faint diamond |

A mark inside a bar sits just past its end. A mark placed as an event
(`.talos-timeline__event.talos-timeline__mark--posted`) keeps its own shape
instead of the diamond.

`.talos-drawer` is a chamfered side panel fixed to the right edge for the detail
of one selected item. It is closed by default; `.is-open` (or `[data-open]`)
slides it in. The demo above overrides `position` so it renders in place.

## Classes

| Class | Role |
| --- | --- |
| `.talos-timeline` | root; `--talos-timeline-label`, `-width`, `-hour`, `-hour0` |
| `.talos-timeline__heads` | fixed label column |
| `.talos-timeline__axis-head` / `__head` | axis label cell / one head per lane |
| `.talos-timeline__head--events` / `__lane--events` | the darker event row |
| `.talos-timeline__title` / `__meta` | head title / count line |
| `.talos-timeline__viewport` / `__tracks` | horizontal scroller / px-wide track column |
| `.talos-timeline__axis` / `__tick` | time axis / tick at `--x` |
| `.talos-timeline__lane` | one lane, hour rules drawn in its background |
| `.talos-timeline__bar` | a run at `--x`, `--w`, `--y` |
| `.talos-timeline__event` | a point in time at `--x`, `--y` |
| `.talos-timeline__edges` | SVG edge layer over the tracks |
| `.talos-timeline__tip` | multi-line hover tip on `.talos-tooltip` chrome |
| `.talos-timeline__swatch` | legend swatch, dressed by a bar variant |
| `.talos-drawer` (`__head`, `__body`, `__title`) | detail side panel; `.is-open` / `[data-open]` |
