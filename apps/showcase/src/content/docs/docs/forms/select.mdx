import Demo from "../../../../components/Demo.astro";

`.talos-select` is a native `<select>` flattened with `appearance: none` so form
semantics and the OS option list survive, then redressed in HUD chrome: the same
[chamfer engine](/docs/components/chamfer/) cut as the text inputs (bottom-right)
and a chevron painted as a background SVG. `--error` / `--success` recolour the
edge, so the state reads off the outline, not the text beside it.

## Default

<Demo>
  <select class="talos-select" style="width:240px">
    <option>eu-west-3</option>
    <option>us-east-1</option>
    <option>ap-south-1</option>
  </select>
</Demo>

```html
<select class="talos-select">
  <option>eu-west-3</option>
  <option>us-east-1</option>
  <option>ap-south-1</option>
</select>
```

Body-font, light weight. `:hover` and `:focus` brighten the edge to
`--talos-edge-strong`; focus brightens it further. The chevron sits 1rem in from
the right edge.

## State — error & success

<Demo>
  <select class="talos-select talos-select--error" style="width:240px">
    <option>— pick a region —</option>
    <option>eu-west-3</option>
  </select>
  <select class="talos-select talos-select--success" style="width:240px">
    <option>eu-west-3</option>
    <option>us-east-1</option>
  </select>
</Demo>

```html
<select class="talos-select talos-select--error">
  <option>— pick a region —</option>
</select>
<select class="talos-select talos-select--success">
  <option>eu-west-3</option>
</select>
```

`--error` paints the edge in `--talos-danger`; `--success` in
`--talos-success`. Nesting the select in a [`.talos-field--error`](/docs/forms/field/)
/ `--success` recolours it the same way without the modifier.

## Disabled

<Demo>
  <select class="talos-select" disabled style="width:240px">
    <option>eu-west-3 (locked)</option>
  </select>
</Demo>

```html
<select class="talos-select" disabled>
  <option>eu-west-3 (locked)</option>
</select>
```

`:disabled` dims to 0.5 and blocks the cursor.

## Classes

| Class | Effect |
| --- | --- |
| `.talos-select` | native chamfered `<select>` with chevron SVG |
| `.talos-select--error` | recolours the edge to `--talos-danger` |
| `.talos-select--success` | recolours the edge to `--talos-success` |
| `:hover` / `:focus` | brightens the edge (focus brightens it further) |
| `:disabled` | dims to 0.5, blocks pointer |

Wrap in a [`.talos-field`](/docs/forms/field/) to pair with a label and a
help/error line; `.talos-field--error` / `--success` recolour the nested select.
